# Play Console 정책 설문 답변 (앱 콘텐츠)

Play Console → 앱 → **정책 및 프로그램 → 앱 콘텐츠**에서 아래 항목을 모두 채워야 출시할 수 있어요.
앱 코드를 확인하고 정리한 답이에요 (2026-10-15 기준: 서버 통신·광고·분석 SDK 없음, 저장은 기기 안 Preferences만).

## 1. 개인정보처리방침
- URL: `https://woojoojumbbang.com/privacy/`
- ⚠ 지금 페이지는 웹사이트 기준이라 **앱 이야기가 없어요.** `privacy-app-section.md`의 문단을 홈페이지 개인정보처리방침에 추가한 뒤 등록하세요.

## 2. 광고
- 앱에 광고가 있나요? → **아니요**

## 3. 앱 액세스 권한
- → **모든 기능을 특별한 액세스 권한 없이 사용할 수 있음** (로그인 없음)

## 4. 콘텐츠 등급 (IARC 설문)
- 카테고리: **참고 자료, 뉴스 또는 교육용이 아닌 그 밖의 앱** → "기타/엔터테인먼트" 계열
- 폭력·성적 콘텐츠·욕설·약물·도박(실제 돈) → 모두 **아니요**
- 사용자 간 소통·콘텐츠 공유 기능 → **아니요** (공유하기는 기기 공유 창으로 다른 앱에 보내는 것뿐, 앱 안에서 사용자끼리 소통하지 않음)
- 위치 공유 → **아니요**
- 디지털 상품 구매 → **아니요**
- 예상 등급: **전체이용가 (3+)**

## 5. 타겟층 및 콘텐츠
- 대상 연령: **18세 이상** 권장 (운세·연애 주제. 13세 미만을 대상으로 하면 '가족 정책' 추가 요건이 생겨요)
- 아동에게 흥미를 끌 수 있나요? → 귀여운 캐릭터가 있으니 Google이 물어볼 수 있어요. **"아니요, 성인 대상 운세 앱"**으로 답하고, 스토어 설명에 '재미로 보는 운세'를 넣어 두었어요.

## 6. 데이터 보안 (Data safety)
| 질문 | 답 |
|---|---|
| 앱이 사용자 데이터를 수집하거나 공유하나요? | **아니요** |
| (참고) 이유 | 생년월일·이름(닉네임)·운세 기록·마스터 경험치는 **기기 안에만 저장**(Capacitor Preferences)되고 개발자나 제3자에게 전송되지 않음. Google 정의상 기기 밖으로 나가지 않는 데이터는 '수집'이 아님 |
| 전송 중 데이터 암호화 | 전송하는 데이터가 없음 |
| 데이터 삭제 요청 방법 | 앱 삭제 또는 앱 데이터 삭제로 즉시 모두 지워짐 |

공유하기를 누르면 운세 글이 사용자가 고른 앱(카카오톡 등)으로 넘어가요. 이건 **사용자가 직접 보내는 것**이라 '공유'로 신고하지 않아도 돼요(Google 안내: 사용자가 시작한 전송은 제외).
