# 플레이 스토어 등록 정보 (복사해서 붙여 넣기용)

Play Console → 앱 → **스토어 등록정보 → 기본 스토어 등록정보**에 넣는 내용이에요. 글자 수 제한 안에 맞춰 두었어요.

## 한국어 (기본 언어: ko-KR)

**앱 이름** (30자 이내)
```
우주 타로 - 타로·사주·별자리
```

**간단한 설명** (80자 이내)
```
오늘의 타로 한 장, 사주와 별자리 운세, 그리고 매일 함께 자라는 나만의 타로 마스터.
```

**자세한 설명** (4,000자 이내)
```
🌙 우주 타로는 귀여운 타로 마스터와 함께 매일 보는 운세 앱이에요.

🃏 타로
• 하루 한 장, 오늘의 카드를 뒤집어 보세요.
• 속마음·썸·재회·연애운·금전·면접·진로·A/B 선택까지 8가지 주제로 카드를 펼쳐요.
• 궁금한 걸 직접 적는 자유 질문도 돼요. 질문에 맞는 주제를 알아서 골라 풀이해요.
• 1909년 라이더–웨이트–스미스 원판 78장 그림을 그대로 썼어요.

🔮 사주
• 생년월일과 태어난 시간으로 오늘의 일진과 총운, 애정·금전·건강·일 운세를 알려 드려요.
• 이번 주 운세 흐름을 별자리처럼 이어 보여 주고, 지난 요일을 눌러 다시 볼 수 있어요.
• 행운의 색·숫자·방향·시간도 함께 확인하세요.

✨ 별자리
• 내 별자리의 오늘 운세와 수호 타로 카드.
• 오늘 달이 지나는 자리로 운세를 읽고, 다른 별자리도 볼 수 있어요.
• 타로 풀이에 내 별자리 이야기를 더해 드려요.

🧙 나의 타로 마스터
• 고양이·판다·강아지·유니콘 등 12명의 마스터 중 한 명을 골라 함께 지내요.
• 매일 들르고 오늘의 카드를 뽑으면 경험치가 쌓여 아기 점술가에서 그랜드 마스터로 자라요.
• 마스터 뒤에는 오늘 밤 서울 하늘의 실제 달 모양이 떠요.
• 좋은 결과엔 함께 웃고, 아쉬운 결과엔 같이 울어 줘요.

🔒 개인정보 걱정 없이
• 회원가입도 로그인도 없어요.
• 입력한 생년월일과 기록은 이 휴대폰에만 저장되고, 어디로도 보내지 않아요.
• 광고가 없어요.

🌗 다크 / 화이트 테마, 한국어 / English 지원

재미로 보는 운세예요. 중요한 결정은 스스로의 판단을 믿으세요.
```
